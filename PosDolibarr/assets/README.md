# Assets pour Dolibarr Caisse POS

## Fichiers requis

### Icône (`icon.png`)
- **Taille** : 1024x1024 pixels
- **Format** : PNG
- **Couleur de fond recommandée** : #2563eb (bleu)
- **Contenu** : Logo ou icône représentant Dolibarr POS

### Splash Screen (`splash.png`)
- **Taille** : 2048x2048 pixels (ou 2732x2732 pour les meilleures performances)
- **Format** : PNG
- **Couleur de fond** : #2563eb (bleu)
- **Contenu** : Logo et texte "Dolibarr Caisse POS"

## Création des assets

Vous pouvez utiliser :
1. **Designer graphique** : Créer les images avec Photoshop, Figma, Sketch, etc.
2. **Outils en ligne** : 
   - [AppIcon.co](https://appicon.co)
   - [IconKitchen](https://icon.kitchen)
   - [MakeAppIcon](https://makeappicon.com)

3. **Expo Asset Generator** :
   ```bash
   npx expo-asset-generator
   ```

Une fois les fichiers créés, placez-les dans ce dossier (`assets/`) avec les noms :
- `icon.png`
- `splash.png`
