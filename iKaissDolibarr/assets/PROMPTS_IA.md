# Prompts pour générer l'icône et le splash screen avec IA

## Prompt pour l'ICÔNE (icon.png - 1024x1024)

```
Create a modern app icon for a Point of Sale (POS) application called "Dolibarr Caisse POS". 
The icon should be:
- 1024x1024 pixels, square format
- Background: solid blue color #2563eb (bright blue)
- Style: minimalist, professional, modern
- Central element: A stylized letter "D" in white, bold and elegant, or a cash register/pos terminal icon
- Design: Clean, flat design with rounded corners, suitable for mobile app stores
- Color scheme: Blue (#2563eb) background with white accents
- Mood: Professional, trustworthy, business-oriented
- No text except the "D" letter or icon symbol
- High contrast for visibility on app store
- PNG format with transparent background or blue background
```

**Version courte :**
```
Modern minimalist app icon, 1024x1024px, solid blue background (#2563eb), white bold letter "D" centered, flat design, rounded corners, professional POS/cash register app style, high contrast, clean business aesthetic
```

---

## Prompt pour le SPLASH SCREEN (splash.png - 2048x2048)

```
Create a splash screen for "Dolibarr Caisse POS" mobile application. 
The splash screen should be:
- 2048x2048 pixels, square format
- Background: solid blue color #2563eb (bright blue)
- Style: Clean, professional, modern, minimalist
- Central elements:
  * Large white bold letter "D" or Dolibarr logo at the top center
  * Below it, the text "Dolibarr Caisse POS" in white, elegant sans-serif font
  * Text should be large, readable, centered vertically and horizontally
- Design: 
  * Minimalist and clean
  * White text on blue background
  * Professional business aesthetic
  * Lots of white space
  * Balanced composition
- Color scheme: Blue (#2563eb) background with white text
- Mood: Professional, trustworthy, modern point of sale system
- No shadows, gradients, or decorative elements - just clean typography and logo
- High contrast for readability
```

**Version courte :**
```
Splash screen 2048x2048px, solid blue background (#2563eb), centered white "D" logo at top, "Dolibarr Caisse POS" text below in large white elegant font, minimalist clean design, professional POS app, high contrast, lots of white space, modern business aesthetic
```

---

## Instructions d'utilisation

1. **Copiez le prompt** ci-dessus dans votre générateur d'images IA (Midjourney, DALL-E, Stable Diffusion, etc.)

2. **Pour l'icône** : Utilisez le prompt "ICÔNE" et spécifiez le format 1:1 (1024x1024)

3. **Pour le splash** : Utilisez le prompt "SPLASH SCREEN" et spécifiez le format 1:1 (2048x2048)

4. **Ajustements** :
   - Si nécessaire, ajoutez "--ar 1:1" (aspect ratio 1:1) dans Midjourney
   - Vous pouvez préciser "--style raw" pour un style plus réaliste
   - "--v 6" pour la dernière version de Midjourney

5. **Téléchargez** les images générées et placez-les dans le dossier `assets/` :
   - `assets/icon.png` (1024x1024)
   - `assets/splash.png` (2048x2048)

6. **Vérifiez** que les fichiers PNG sont bien nommés et dans le bon dossier avant de lancer le build.
