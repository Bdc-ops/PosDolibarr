# Politique de Confidentialité - iSales Dolibarr

**Date d'effet** : 7 janvier 2026  
**Dernière mise à jour** : 7 janvier 2026

## 1. Introduction

Anexys ("nous", "notre", "nos") exploite l'application mobile iSales Dolibarr (ci-après dénommée "l'Application").

Cette page vous informe de nos politiques concernant la collecte, l'utilisation et la divulgation de données personnelles lorsque vous utilisez notre Application.

## 2. Données Collectées

### 2.1 Données que vous fournissez

- **Identifiants de connexion** : URL de votre instance Dolibarr, clé API
- **Données métier** : Les données que vous consultez ou créez dans l'Application proviennent de votre instance Dolibarr (produits, clients, commandes, factures)

### 2.2 Données collectées automatiquement

- **Localisation GPS** : Avec votre consentement explicite, nous collectons votre position géographique pour calculer les itinéraires vers vos clients
- **Logs techniques** : Pour le débogage et l'amélioration de l'Application
- **Données de cache** : Stockées localement sur votre appareil pour le mode hors ligne

## 3. Utilisation des Données

Nous utilisons les données collectées pour :

- Vous permettre de vous connecter à votre instance Dolibarr
- Afficher et gérer vos données métier (produits, clients, commandes, factures)
- Calculer des itinéraires vers vos clients (avec votre autorisation GPS)
- Assurer le fonctionnement du mode hors ligne
- Améliorer les performances et la stabilité de l'Application
- Fournir un support technique

## 4. Stockage et Sécurité des Données

### 4.1 Où sont stockées vos données ?

- **Données métier** : Stockées exclusivement sur VOTRE instance Dolibarr. Nous n'hébergeons AUCUNE de vos données métier.
- **Identifiants** : Stockés de manière sécurisée sur votre appareil mobile (AsyncStorage chiffré)
- **Cache hors ligne** : Stocké localement sur votre appareil, supprimé lors de la déconnexion

### 4.2 Sécurité

- Toutes les communications avec votre instance Dolibarr utilisent HTTPS
- Les identifiants sont stockés de manière sécurisée sur l'appareil
- Aucune donnée n'est transmise à des serveurs tiers
- Le cache est supprimé lors de la déconnexion

## 5. Partage des Données

Nous ne vendons, n'échangeons et ne transférons PAS vos données personnelles à des tiers.

Vos données restent entre :
- Vous (utilisateur de l'Application)
- Votre instance Dolibarr (que VOUS contrôlez)

## 6. Droits des Utilisateurs (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

- **Droit d'accès** : Accéder à vos données personnelles
- **Droit de rectification** : Corriger vos données inexactes
- **Droit à l'effacement** : Supprimer vos données (bouton "Déconnexion" dans l'app)
- **Droit à la portabilité** : Exporter vos données depuis votre instance Dolibarr
- **Droit d'opposition** : Vous opposer au traitement de vos données

Pour exercer ces droits, contactez-nous à : **support@anexys.fr**

## 7. Permissions Requises

### iOS
- **Localisation** : "Autoriser l'accès à votre position pendant l'utilisation"
  - Utilisée uniquement pour calculer les itinéraires vers les clients
  - Vous pouvez refuser sans perdre les autres fonctionnalités

### Android
- **ACCESS_FINE_LOCATION** : Localisation GPS précise
- **ACCESS_COARSE_LOCATION** : Localisation réseau approximative
- **INTERNET** : Communication avec votre instance Dolibarr

## 8. Cookies et Technologies de Suivi

L'Application n'utilise PAS de cookies ni de technologies de suivi publicitaire.

Le seul stockage local concerne :
- Vos identifiants de connexion
- Le cache hors ligne (pour améliorer les performances)
- Les logs de débogage (supprimables)

## 9. Services Tiers

L'Application n'intègre AUCUN service tiers de tracking ou de publicité.

Les seules connexions externes sont :
- Votre instance Dolibarr (configurée par vous)
- API Expo (pour les mises à jour de l'Application)

## 10. Protection des Mineurs

L'Application n'est pas destinée aux personnes de moins de 18 ans. Nous ne collectons pas sciemment d'informations personnelles auprès de mineurs.

## 11. Modifications de cette Politique

Nous pouvons mettre à jour cette politique de confidentialité occasionnellement. Nous vous notifierons de tout changement en publiant la nouvelle politique dans l'Application et en mettant à jour la "Date de dernière mise à jour".

## 12. Suppression de vos Données

Pour supprimer toutes vos données de l'Application :

1. Ouvrir l'Application
2. Aller dans "Mon compte"
3. Appuyer sur "Déconnexion et vider le cache"
4. Désinstaller l'Application

**Note** : Les données sur votre instance Dolibarr ne seront PAS supprimées (car elles sont sous votre contrôle).

Nous traitons vos données sur la base de :

- **Consentement** : Pour la localisation GPS
- **Exécution du contrat** : Pour fournir les services de l'Application
- **Intérêt légitime** : Pour améliorer l'Application et assurer la sécurité
