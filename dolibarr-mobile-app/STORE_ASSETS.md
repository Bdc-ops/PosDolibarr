## 🖼️ Spécifications Screenshots

### iOS (iPhone 6.7" - iPhone 14 Pro Max ou 15 Pro Max)
- Résolution : **1290 x 2796 pixels**
- Format : PNG ou JPEG
- Nombre : **Minimum 3** (recommandé : 6-8)
- Ordre suggéré :
  1. Dashboard / Écran d'accueil
  2. Liste des produits (vue grille)
  3. Fiche client avec carte
  4. Création de commande
  5. Détails de facture
  6. Statistiques avec graphiques
  7. Page Mon compte
  8. Configuration / Paramètres

### Android (Téléphone)
- Résolution : **1080 x 1920 pixels** minimum (ratio 16:9)
- Ou : **1440 x 2560 pixels** (Full HD+)
- Format : PNG ou JPEG (24-bit, pas de transparence)
- Nombre : **Minimum 2** (recommandé : 4-8)
- Même ordre que iOS

### Tablette Android (optionnel mais recommandé)
- Résolution : **2048 x 2732 pixels** (iPad Pro 12.9")
- Nombre : 2 minimum

## 🎨 Conseils Design Screenshots

1. **Utilisez un device frame** : https://mockuphone.com ou https://www.figma.com
2. **Ajoutez du texte descriptif** sur chaque screenshot (titre + phrase courte)
3. **Utilisez des données réalistes** (pas de "Lorem Ipsum")
4. **Thème cohérent** : Gardez les mêmes couleurs de fond pour tous les screens
5. **Langue** : Français pour la version FR, anglais pour la version EN

## 📄 Assets Graphiques Requis

### 1. Icône de l'application
- **Fichier** : `./assets/icon.png`
- **Taille** : 1024 x 1024 px
- **Format** : PNG avec transparence
- **Coins** : Ne pas arrondir (le système le fait)
- **Padding** : Laisser 5-10% de marge sur les bords

### 2. Splash Screen
- **Fichier** : `./assets/splash.png`
- **Taille** : 1284 x 2778 px (ratio iPhone portrait)
- **Format** : PNG
- **Contenu** : Logo centré + couleur de fond (`#004E89`)

### 3. Icône Adaptative Android
- **Fichier** : `./assets/adaptive-icon.png`
- **Taille** : 1024 x 1024 px
- **Format** : PNG avec transparence
- **Zone de sécurité** : Cercle de 66% au centre (le reste peut être coupé)

### 4. Banner Google Play (Optionnel)
- **Taille** : 1024 x 500 px
- **Format** : PNG ou JPEG
- **Utilisation** : Mis en avant sur Google Play
