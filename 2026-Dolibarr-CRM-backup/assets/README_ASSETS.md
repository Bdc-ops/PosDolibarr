# Assets nécessaires

Pour que l'application fonctionne correctement, vous devez créer les fichiers suivants dans ce dossier :

1. **icon.png** - 1024x1024px (icône de l'application)
2. **splash.png** - 1242x2436px (écran de démarrage)
3. **adaptive-icon.png** - 1024x1024px (icône Android adaptative)
4. **favicon.png** - 48x48px (icône web)

## Outils recommandés

- [App Icon Generator](https://www.appicon.co/) - Pour générer toutes les tailles
- [Expo Asset Generator](https://docs.expo.dev/guides/app-icons/) - Documentation officielle

## Temporaire

Pour tester rapidement, vous pouvez utiliser des images de placeholder ou laisser les fichiers vides.
L'application fonctionnera mais sans icônes personnalisées.
