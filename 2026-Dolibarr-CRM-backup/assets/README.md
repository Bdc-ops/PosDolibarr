# Assets de l'application

## Images créées

Les images suivantes ont été créées automatiquement avec des valeurs par défaut :

- ✅ `icon.png` (1024x1024) - Icône principale de l'application
- ✅ `splash.png` (1242x2436) - Écran de démarrage
- ✅ `adaptive-icon.png` (1024x1024) - Icône adaptative Android
- ✅ `favicon.png` (48x48) - Favicon pour le web

## Personnalisation

Pour personnaliser ces images :

1. **Créer vos propres images** avec les dimensions exactes
2. **Remplacer les fichiers** dans ce dossier
3. **Redémarrer Expo** pour voir les changements

### Outils recommandés

- [App Icon Generator](https://www.appicon.co/) - Génère toutes les tailles nécessaires
- [Figma](https://www.figma.com/) - Design d'icônes
- [Canva](https://www.canva.com/) - Création simple d'images

### Dimensions requises

- **icon.png** : 1024x1024px (PNG)
- **splash.png** : 1242x2436px (PNG) 
- **adaptive-icon.png** : 1024x1024px (PNG)
- **favicon.png** : 48x48px (PNG)

## Note

Les images actuelles sont des placeholders générés automatiquement. 
Vous pouvez les remplacer par vos propres designs à tout moment.
